# 아이기론 개편 계획 (2026-11-22)

> 캡틴 결정(11-22): "1번으로 가야겠어! 전부 수정해! 끊을 건 끊고 단순함에 집중하자."
> 1번 = **정부·국가 바이오안보를 첫 고객**으로, 그 경로의 첫걸음은 정부 과제·용역.

## 1. 한 줄 정의

**극지가 깨우는 위협을 헤임달이 식별하고, 발할라가 막을 수 있는지 판정한다.**

| 자리 | 층 | 역할 | 제품에서의 위치 |
|---|---|---|---|
| 감지 | 극지 영토 감시 | 영구동토 해빙·극지 이상 — 묻힌 병원체가 깨어나는 조건 | 연구·브랜드 자산(수익 기대 낮음, 비용 낮게 유지) |
| 식별 | 헤임달 (Stage 0) | 위협 병원체 계통·변이 추적, 방어적 유전체 스크리닝 | 발할라의 엔진 |
| 대응 | 발할라 (Stage 8) | 백신·치료제·비축·조달이 그 위협을 막는가, 어디가 비었나 | **제품** — "대응제 준비태세 인텔리전스" |

이 사슬에 들어가지 않는 것은 끈다. 판단 기준은 이 표 하나다.

### 2단계에서 반드시 같이 맞출 것 (끄기만 하면 생기는 거짓)

- **부정적 공간 감시**: 끈 층의 지표가 '평소 활발하던 채널이 조용해졌다'로 읽히면 거짓 급감 경보가 난다 → 끈 층 지표는 판정 대상에서 뺀다.
- **소스 건강**: 끈 소스가 `중단`으로 세어지면 매시간 거짓 고장이 뜬다 → 끈 소스는 건강 집계에서 뺀다(꺼짐으로 표시).
- **관측값 저장**: 끈 층은 '판정 안 함'을 매시간 쌓지 않는다(꺼짐은 측정 실패가 아니다).
- **경보·텔레그램**: 전 세계 발병 경보(GAI·위키·SNS·무역 급증)는 끈다. 발할라 판정 변화만 알릴지는 캡틴 결정.

## 4. 0단계 — 극지 과거 자료 (이 PR)

11-19~21 실측: 극지 8곳이 매일 11~12시 UTC 부터 자정까지 '기상 자료 없음'(사유 전부 HTTP 429).
원인: 기준선(10년)·추세(16년) 요청의 끝 날짜가 `오늘 - 5일` 이라 캐시 키가 매일 바뀌어, 수천 일치 요청 16번이 매일 새로 나갔다.

수리: 구간을 둘로 자른다.
- 과거분 `[16년 전 그 달 1일, 이번 달 1일 전날]` — 이번 달 동안 키가 같고, 기준선과 추세가 나눠 쓴다 → **한 곳당 한 달 1번**.
- 이번 달분 `[이번 달 1일, 끝 날짜]` — 길어야 한 달치, 날마다(월중 값이 얼어붙지 않게).
- 돌려주는 행은 예전과 같다(요청 구간 안, 겹침 없음). 계산식은 그대로다.

요청량: 수천 일치 16번/일 → 수천 일치 8번/월 + 한 달치 이하 8번/일. (가중치로 몇 회인지는 공식 문서를 못 봐 추정만 가능 — 판정은 배포 뒤 로그.)

판정 기준(배포 뒤): 성공 = 낮 12~23시 `❌ 극지 관찰: 모든 관측지 기상 자료 없음` 이 사라짐 · 실패 = 그래도 뜸(그러면 #135 의 한도 종류 사유로 다음 원인을 가른다) · 판정 안 함 = 배포 후 24시간 미만.

## 6. 다시 불어나지 않게 하는 규칙

1. 새 기능은 **사슬의 어느 칸인지** 답해야 한다.
2. **정답 출처**(무엇으로 채점하나)가 있어야 한다.
3. **하나를 넣으면 하나를 뺀다.**
4. 보관은 폴더가 아니라 git 태그다 — 지운 코드는 AI 세션 토큰도, CI 시간도 먹지 않는다. 복원은 태그에서.
5. 개편 기간에는 코드를 고치는 세션을 하나로 둔다(같은 브랜치에 여러 세션이 동시에 커밋했다 — 11-18·19).

## 7. 대가와 위험

- 끈 층은 관측값 시계열이 끊긴다. 다시 켜도 빈 구간이 남는다.
- 외부에 보여 준 화면 일부가 사라진다.
- 발할라 일부 조각(준비태세·백신 공급)은 로컬 파일 값이라, 실측 데이터가 얼마나 쌓였는지 2단계 전에 따로 본다.
- 비축량은 대외비라 데이터 접근이 막힐 수 있다 — 정부 과제로 시작하는 이유이기도 하다.
