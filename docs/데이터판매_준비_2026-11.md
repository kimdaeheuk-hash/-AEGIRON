# 데이터 판매 준비 — 2026-11-16

> 캡틴 지시: "보고해서 데이터로 집계해 판매할 수 있게 전부 셋팅해야 해".
> 이 문서는 무엇을 갖췄는지, 원천별 상업 이용 조건이 무엇인지, 캡틴이 결정할 것이 무엇인지 정리한다.
> **법률 자문이 아니다.** 원천 약관은 2026-11-16 웹 검색으로 확인한 요약이며, 계약 전에 원문과 법률 검토가 필요하다.

## 1. 갖춘 것 (코드)

| 장치 | 위치 | 내용 |
|---|---|---|
| 보유량 집계 | `GET /api/data-inventory` · 로그 `📦 데이터 보유량` | 테이블별 행 수·첫/마지막 시각·기록 일수, 누적 파일(매시 수집 기록 `signals_log.jsonl`) 줄 수·기간. 직접 센 값. 매일 한 번 + 기동 직후 로그 |
| 데이터셋 카탈로그 | `GET /api/datasets` | 6개 데이터셋 정의·칸·측정/추정 구분·원천·상업 상태·보유량 |
| 내보내기 | `GET /api/datasets/{id}/export?format=csv\|json` | 키 없이 = 무료 표본(최근 7일·100행, allowed·review). 고객 키(`X-Data-Key`) = 기간 지정·최대 5만 행(allowed 만). 호출은 라벨별로 기록 |
| 고객 키 | 환경변수 `EPIWEATHER_DATA_KEYS="라벨:키,…"` | 키 값은 Railway 변수에만. 문서·커밋에 적지 않는다 |
| 실적표 | `GET /api/track-record` | 예측 채점·선행성 원장·선행일수 실측·주간 방향 예측·경보 월별 건수 — 합치지 않고 나란히 |
| 판매 페이지 | 웹 `/{ko,en,fr}/data` | 보유량·실적·카탈로그·상업 상태·표본 내려받기·문의 |

## 2. 데이터셋과 상업 상태

상태: **allowed** = 상업 이용 가능(출처 표기 조건 포함) · **review** = 조건 확인·법률 검토 전(표본만) · **blocked** = 지금 방식으로는 상업 이용 불가(표본·유료 모두 제외).

| 데이터셋 | 원천 | 상태 | 이유 |
|---|---|---|---|
| 예측 원장 | 자체 산출 | allowed | 우리 기록 |
| 선행성 원장 | 자체 산출 + 공식 선언일(사실) | allowed | 우리 기록 |
| 경보 이력 | 자체 산출(근거에 원천 값) | review | 근거 문장에 WHO 등 원천 값이 섞임 |
| 발생 보도(구조화) | WHO DON·지역 보건기구·언론 | review | 원문은 빼고 사실 칸만 내보내지만 WHO 자료는 상업 이용에 허가 필요 |
| 한국 해외유입 주간 보고서 | 자체 + 인천공항 운송실적 + OpenFlights + 일본 IDWR | review | OpenFlights ODbL(출처·동일조건), IDWR 재이용 조건 미확인 |
| 관측값 — 여행경보 | CDC | allowed | CDC 웹 자료는 별도 표기 없으면 공공 영역(출처 표기) |
| 관측값 — 재난 | GDACS | review | EC 재사용 정책 계열로 보이나 2025-03 약관 원문 미확인 |
| 관측값 — 토지 | NASA FIRMS | review | 조건 미확인 |
| 관측값 — 삼림 | Global Forest Watch | review | 데이터셋별 라이선스 미확인 |
| 관측값 — 극지·기후 | Open-Meteo | **blocked** | 무료 API 는 비상업 전용 |
| 관측값 — 무역 | UN Comtrade | **blocked** | 상업적 재배포 제한, 허가 필요 |

## 3. 원천별 약관 요약 (2026-11-16 확인)

- **Open-Meteo** — 무료 API 는 비상업 전용(하루 1만 회 미만). 상업 이용은 유료 구독 필요. 데이터는 CC BY 4.0(출처 표기, 변경 표시).
  ⚠️ **판매 전에 반드시 유료 구독으로 바꿔야 함.** 회사 웹사이트·유료 서비스에 쓰는 것 자체가 상업 이용으로 볼 여지가 있다.
  출처: [약관](https://open-meteo.com/en/terms) · [가격](https://open-meteo.com/en/pricing)
- **UN Comtrade** — 라이선스가 재배포·출판·상업적 이용을 제한, 허가는 comtrade@un.org. 원자료 재배포는 Premium Pro 구독 조건.
  가공(변형) 데이터는 자체 규칙으로 배포 가능하다는 비공식 위키 설명이 있으나 공식 입장 아님.
  출처: [라이선스](https://comtrade.un.org/licenseagreement.html) · [위키(비공식)](https://comtradewiki.azurewebsites.net/?p=893) · [UN 샵](https://shop.un.org/de/node/55)
- **WHO** — 대부분 CC BY-NC-SA 3.0 IGO: 비상업 재사용은 허가 불필요, **상업 이용은 허가 필요**. DON 개별 조건은 미확인.
  출처: [WHO 저작권·허가](https://www.who.int/about/who-we-are/publishing-policies/copyright)
- **CDC** — 별도 저작권 표기가 없으면 공공 영역, 출처 표기 요청. 단 CDC 로고는 상표, 신디케이션 자료는 문구 변경 금지, 유료로 CDC 콘텐츠를 재배포하는 것은 명시 허가가 필요하다는 문구가 있음 → 우리 상품은 CDC 원문이 아니라 경보 등급·제목 메타데이터 수준으로 쓴다.
  출처: [CDC 자료 이용](https://cdc.gov/other/agencymaterials.html)
- **OpenFlights** — ODbL(데이터베이스) + DbCL(내용). ODbL 은 상업 이용 허용, 출처 표기·동일조건(파생 DB 공개 시 같은 라이선스) 조건.
  출처: [OpenFlights 데이터](https://openflights.org/data) · [FAQ](https://openflights.org/faq)
- **GDACS** — EC 결정 2011/833/EU 재사용 정책을 따른다고 안내(보통 CC BY 4.0). "지표일 뿐 단독 의사결정에 쓰지 말라"는 면책. 2025-03 약관 PDF 원문 확인 필요.
  출처: [GDACS 이용약관](https://gdacs.org/About/termofuse.aspx) · [2025-03 약관](https://www.gdacs.org/documents/2025/GDACS_Terms_of_use_Mar_25.pdf)
- **GDELT(프로젝트 원자료)** — 학술·상업·정부 어떤 용도든 무제한, 인용·링크 조건. (GDELT Cloud 무료 등급은 다름 — 비생산·비상업)
  출처: [GDELT 소개](https://www.gdeltproject.org/about.html)
- **Wikimedia 페이지뷰** — CC0 1.0. 문서 본문은 CC BY-SA(별개).
  출처: [접근 정책](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/documentation/access-policy.html)
- **인천공항 운송실적(공공데이터 15062056)** — 이용허락범위 제한 없음.
  출처: [공공데이터포털](https://www.data.go.kr/data/15062056/fileData.do)
- **Nextstrain** — 공개 데이터는 원 생산자 표기 조건의 재공유 허용, GISAID 유래 자료는 재공유 제한. 우리는 GenBank·공개 빌드 요약만 쓴다(확인 필요).
  출처: [Nextstrain 데이터 내려받기](https://docs.nextstrain.org/en/latest/guides/share/download-data.html)
- **일본 IDWR(JIHS, 구 NIID)** — 공식 재이용 조건을 찾지 못함. 출처 표기 관행만 확인. → review 유지, JIHS 문의 필요.
  출처: [IDWR](https://idsc.nih.go.jp/en/surveillance/idwr/index.html)
- **미확인**: NASA FIRMS, Global Forest Watch, Mastodon(게시자 수만 셈 — 게시물 본문은 저장·판매하지 않음), Google News 제목, ProMED·지역 보건기구 각각.

## 4. 캡틴 결정 필요

1. **Open-Meteo 유료 구독** — 판매·회사 서비스 전에 전환. 비용 확인 후 결정(공식 가격 페이지에서 확인할 것 — 2차 사이트 숫자가 서로 다름).
2. **UN Comtrade 허가 요청** — comtrade@un.org 에 "급증 배수 등 가공 지표" 판매 가능 여부 문의할지.
3. **WHO 상업 이용 허가** — 발생 보도 구조화 데이터 판매 시 필요할 수 있음. 허가 신청할지, 아니면 WHO 유래 칸을 빼고 팔지.
4. **가격** — 지금 카탈로그·페이지는 "미정 — 문의". 파일럿 단가를 정할지.
5. **고객 키 발급** — 첫 파일럿 기관이 정해지면 `EPIWEATHER_DATA_KEYS` 에 라벨:키를 넣는다(캡틴이 Railway 에서 직접, 키 값은 대화에 남기지 않음).
6. **이용약관·개인정보** — 데이터 이용약관(재배포 금지·면책·출처 표기) 초안은 법률 검토 후. 사업자 등록·세금계산서 발행 주체.
7. **무료 베타 수신자** — 주간 보고서를 보낼 3~5곳.
