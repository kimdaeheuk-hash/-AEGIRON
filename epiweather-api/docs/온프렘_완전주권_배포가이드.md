# AEGIRON 완전 주권(온프렘) 배포 가이드

정부·국방 조달의 **데이터 국외반출 금지** 요건을 충족하기 위해, AEGIRON의 모든
NVIDIA 추론(유전체 + 텍스트)을 사설 GPU 위 **온프렘 NIM 클러스터**로 라우팅하는
방법. 환경변수 **하나**로 전 층이 전환된다.

## 무엇이 바뀌나

| 층 | 모듈 | 클라우드(기본) | 온프렘(완전 주권) |
|---|---|---|---|
| 유전체 자연스러움 | `evo2_naturalness` | health.api.nvidia.com | `$ONPREM/v1/biology/arc/evo2-40b/generate` |
| 상동성 검색 | `msa_homology` | health.api.nvidia.com | `$ONPREM/v1/biology/colabfold/msa-search/predict` |
| 텍스트 신호 추출 | `aegiron_model` | integrate.api.nvidia.com | `$ONPREM` (또는 텍스트 전용 URL) |

`$ONPREM` = `AEGIRON_NVIDIA_ONPREM_BASE`.

## 설정 (한 줄)

```bash
# 이 하나로 유전체·텍스트가 전부 온프렘으로 → sovereignty_posture=full_onprem
AEGIRON_NVIDIA_ONPREM_BASE=https://nim.internal.aegiron.gov
NVIDIA_API_KEY=<온프렘 NIM 게이트웨이 토큰>   # 온프렘도 Bearer 인증을 그대로 씀
```

- 텍스트 층만 다른 호스트로 보내려면 `AEGIRON_NIM_BASE_URL`을 따로 지정(우선함).
- 민감 데이터 강제 차단까지 켜려면 `AEGIRON_REQUIRE_LOCAL=on` — 완전 주권 경로가
  아니면 외부로 나가기 전에 fail-closed.

## 온프렘 NIM 세우기 (요약)

1. NGC(NVIDIA GPU Cloud) 카탈로그에서 NIM 컨테이너 pull:
   - Evo2: `nvcr.io/nim/arc/evo2-40b`
   - ColabFold MSA: `nvcr.io/nim/colabfold/msa-search`
   - 텍스트 LLM: 원하는 instruct 모델 NIM(예: `nvcr.io/nim/meta/llama-3.1-8b-instruct`)
2. 사설 GPU 노드에서 기동(모델별 GPU/VRAM 요건은 각 NIM 문서 참조).
3. 사내 리버스 프록시(예: `https://nim.internal.aegiron.gov`)로 묶어 단일 베이스 URL
   제공 + Bearer 토큰 게이트.
4. AEGIRON API 컨테이너에 위 환경변수 주입 → 재기동.

## 검증

```bash
curl -s localhost:8000/api/ai/provider-status | jq '.nvidia | {sovereignty_posture, fully_sovereign, layer_endpoints}'
# 기대: sovereignty_posture="full_onprem", fully_sovereign=true,
#       layer_endpoints 두 값 모두 온프렘 호스트
```

- `full_onprem` : 전 층 온프렘 — 완전 주권(데이터가 국경을 안 넘음)
- `partial`     : 일부만 온프렘(예: 텍스트만) — 완전 주권 아님
- `cloud`       : 전부 NVIDIA 클라우드(기본)

## 정직성 주의

- 온프렘으로 돌려도 **모델 자체(Evo2 등)는 여전히 NVIDIA/Arc가 만든 것**이다. 완전
  주권이 보장하는 것은 "데이터가 밖으로 안 나간다"이지 "모델 IP까지 국산"이 아니다.
  모델 IP 독립은 별도 트랙(training_data.py 증류 + 자체 학습)이다.
- 온프렘 다운 시 동작(정직하게 명시):
  - **유전체(Evo2/MSA)**: 조용히 `ok=False`. 클라우드로 자동 폴백하지 않는다.
  - **텍스트(aegiron_model)**: `AEGIRON_REQUIRE_LOCAL=on`이면 외부 LLM 폴백까지
    모두 차단(`blocked`) — 공개 뉴스라도 미국 API로 안 나간다(완전 주권 실질 보장).
    `off`(기본)면 온프렘 다운 시 공개 뉴스 추출은 Anthropic으로 폴백할 수 있다.
    → **완전 주권 배포에서는 `AEGIRON_REQUIRE_LOCAL=on`을 반드시 함께 켤 것.**
  - 지어낸 값으로 채우지 않는다. 온프렘 모드에서는 온프렘이 곧 SPOF이니
    이중화가 필요하다.
