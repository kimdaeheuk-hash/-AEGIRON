08-29 하루치 실측(UTC 00~23시 24주기):

    LLM 재분류 성공 10주기 / 실패 14주기(58%) · 18~23시는 6주기 연속 실패
    실패 14회의 사유가 **전부** Cerebras 402 + Groq JSONDecodeError
    Groq 쪽 402·429 는 **0건**

**한도 문제가 아니었다.** 그런데 그걸 아는 데 하루가 걸렸다 — 코드가
`finish_reason` 을 한 번도 안 찍어서, 서로 다른 실패가 전부 같은 이름으로만
남았기 때문이다. **GroqWatch(8/25)·Mobility(8/28) 와 같은 모양이 또 나왔다.**

### 원인을 좁힌 것은 대조였다

NewsWatch 는 **같은 모델(`openai/gpt-oss-120b`)·같은 파라미터**로 같은 24주기 중
22번 성공했다. 다른 건 출력 길이뿐이다 — NewsWatch 는 두 문장, 재분류는 60개
JSON 배열. 파싱 실패 지점도 char 0·2·33·167·205·405·756·1079·1360·1552·1612 로
제각각인데, 이건 형식이 틀린 모양이 아니라 **매번 다른 길이에서 잘린** 모양이다.

### 고친 것 (4겹 — 하나가 뚫려도 다음이 받는다)

1. **출력을 31배 줄였다.** 개체 배열 → 번호만. 실측 60개 기준 1,775자 → 57자.
   두 형식을 모두 받으므로 모델이 옛 습관대로 답해도 된다.
2. **상한을 우리가 쥔다.** `max_tokens=1500`. 예전엔 안 줘서 제공자 기본값에
   맡겼고 그 값이 얼마인지 아무도 몰랐다. `reasoning_effort=low` 도 보내되
   **400 이면 빼고 재시도한다** — 모델 ID 를 찍었다가 404 를 맞은 8/28 의 교훈.
3. **잘려도 건진다.** 완성된 원소까지만 파싱한다. 08-29 의 실제 실패(char 205
   에서 잘림)를 재현하면 **예전 0개 → 지금 2개 피드**가 분류된다.
4. **`finish_reason` 을 사유에 싣는다.** `length` 면 잘린 것, `stop` 이면 모델이
   애초에 JSON 을 안 준 것 — 조치가 다르다.

### ★ 답하지 않은 제목을 `False` 로 채우지 않는다 ★

잘린 뒤를 "무관함" 으로 메우면 **실제 발병 보도가 조용히 덮인다.** 잘림보다
이쪽이 훨씬 나쁘다 — 이 제품이 파는 건 남보다 먼저 아는 것인데, 신호를 지우는
쪽으로 틀리면 늦는 정도가 아니라 아예 못 본다. 답 없는 제목은 키워드 값을
그대로 쓴다. 테스트가 이 성질을 고정하고, 되돌리면 실제로 깨지는 것을 확인했다.

### ⚠️ 아직 확인 안 된 것 — 다음 점검 때 할 일

이 샌드박스는 Groq 에 못 닿아 **라이브 검증을 못 했다.** GDACS 때와 같은 상황이다.

1. `LLM 재분류 N개 피드` 가 매 주기 찍히는가. **N 이 12 근처면 정상**이다.
2. `(제목 N/60 — 응답 잘림)` 이 붙는가. 붙으면 **여전히 잘리고 있다**는 뜻이다.
   그때는 실패 사유의 `finish_reason` 을 읽어라:
   - `length` → 상한이 아직 모자라다. `MAX_COMPLETION_TOKENS` 를 올려라.
   - `stop` → 잘린 게 아니라 모델이 JSON 을 안 준다. 프롬프트 문제다.
3. `reasoning_effort` 가 거부되는지는 로그로 안 보인다(조용히 빼고 재시도한다).
   위 1·2 가 계속 나쁘면 그때 의심해라.
4. **Cerebras 402 는 안 고쳤다.** 무료 쿼터가 끝난 것이라 우리 쪽 버그가 아니다.
   Groq 폴백으로 버티는 구조이고, 캡틴이 유료 전환/다른 무료 제공자를 정해야 한다.

### 곁가지 — 새 형식이 만든 새 함정

번호 배열은 각주 `[1]` 도 "말이 되게" 파싱된다. 예전 개체 형식은 그런 걸
파싱하다 시끄럽게 실패했는데, 번호 형식은 **조용히 틀린 답**이 된다. 그래서 모든
`[` 를 후보로 훑어 쓸 수 있는 원소가 가장 많은 것을 고른다. 빈 배열 `[]` 은
실패가 아니라 "해당 없음" 이라는 정당한 답으로 받는다 — 이걸 실패로 치면
조용한 날마다 키워드로 떨어진다.
